# Repository workflow

## Branch policy

- The development branch is `dev` in the main repository: `rradkov/better_thermostat_UnderflowHeating`.
- All new changes for this repository must be made and published to `dev` first.
- Do not publish unconfirmed development changes directly to `main`.
- After the user confirms the changes, promote the confirmed state from `dev` to `main`.

## Repository consolidation

The former `rradkov/better_thermostat_UnderflowHeating-dev` repository was consolidated into the `dev` branch of `rradkov/better_thermostat_UnderflowHeating`.
