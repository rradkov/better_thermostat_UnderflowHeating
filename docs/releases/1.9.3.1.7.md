# 1.9.3.1.7 — Home Assistant 2026.11 compatibility

Released on 2026-11-05.

## Fixed

- Restore Child Lock correctly on Home Assistant 2026.11. The integration now
  uses `RestoreStateData.async_get_stored_state()` when available, with a
  fallback for older supported Home Assistant versions. This fixes the startup
  failure that left Better Thermostat climate entities unavailable after the
  removal of `RestoreStateData.last_states`.
- Backport the compatibility fix and regression tests from upstream
  [PR #2858](https://github.com/KartoffelToby/better_thermostat/pull/2858).

## Changed

- Warm Floor extends maintenance pauses as the room rises above its target
  band. A positive temperature slope or a short-term temperature average above
  the one-hour average can extend the pause further.
- The additional pause decreases as the measured target excess decreases.
  The four-minute minimum actuator pulse is retained, and no fixed maximum
  pause is introduced. Below-target heating remains under normal room control.

## Compatibility and upgrade

- Requires Home Assistant **2026.9.0 or later**, including compatibility with
  **2026.11.0**, and its supported Python runtime.
- Update through HACS or replace the integration files, then restart Home
  Assistant. The fix can be installed when Home Assistant is already on 2026.11.
- Existing thermostat configuration is retained; no manual migration is needed.
- Experimental secondary-device Boost remains suspended. The standard Boost
  temperature preset and normal secondary-device cooling remain available.

## Verification

- The Warm Floor sustain and duty-cycle regression suite passes: **63 tests**.
- The focused release checks pass: **80 tests** covering Warm Floor,
  production isolation of secondary-device Boost, metadata, and documentation.
- Child-lock lookup passes **25 focused compatibility cases**, including new
  and legacy restore APIs, stored ON/OFF/unknown states, missing state, and
  configuration precedence. The upstream Home Assistant fixture-based tests
  are included; their local execution is blocked by the Windows host's missing
  POSIX `fcntl` module.
- Python compilation, Ruff checks, formatting, and diff validation pass for
  the changed code.
- Live startup verification on Home Assistant **2026.11.0** confirms that
  Better Thermostat climate entities load, room control and downstream heating
  states agree, and Warm Floor diagnostics refresh, with no Better Thermostat
  errors after restart.
