# Better Thermostat UnderflowHeating 1.9.3.1.5

## Added

- Recovery-triggered control passes for controlled heaters and the optional outdoor sensor.
- Focused regression tests covering unavailable-to-available transitions.

## Changed

- Optional outdoor input handling preserves the last valid heating decision while the sensor is unavailable.
- The implementation remains neutral regarding heat source, relay hardware, integrations, and room layout.

## Fixed

- A reconnect could leave Warm Floor or normal heating waiting for a future unrelated state change instead of recalculating immediately.

## Upgrade

Restart Home Assistant once after installing the release so the custom integration is loaded from the new release tree.
